# SF6 Battlelog Dashboard 使い方

バージョン 3.2.0

## ダウンロード

最新版は [リリースページ](https://github.com/bivexum/sf6_dashboard_released/releases/latest) から入手できます。

- ダウンロードするのは `sf6_dashboard_bundle_vX.Y.Z.zip`（X.Y.Z は版番号）です
- 一緒に並んでいる **Source code (zip) / Source code (tar.gz) は不要**です（GitHub が自動で付けるもので、アプリは入っていません）
- すでに使っている人は、アプリ内のアップデートで更新できます（v2 系の人は一度 v3.0.0 に更新されたあと、もう一度最新版への更新が案内されます）
- 更新の最後に「cmd.exe - アプリケーション エラー（0xc0000142）」が出てアプリが立ち上がらないことがあります（v3.0.0 以前の版から更新したとき）。更新は完了しているので、OK を押してから、いつもどおり起動してください

---

## 事前に必要なもの

1. **Python**（推奨: 3.11 or 3.12）
   - すでに入っていればOK
   - 入っていない場合は、下記Python公式インストーラで入れてください
   - インストール時に「**Add python.exe to PATH**」にチェックを入れてください

[Python 3.12.10 インストーラ (Windows 64bit)](https://www.python.org/ftp/python/3.12.10/python-3.12.10-amd64.exe)

2. **画面の解像度が 1920×1080（フルHD）以上のモニター**
   - アプリは 1080p 以上のモニターで、窓を最大化して使う前提で作っています
   - それより小さい画面や窓では、表や項目名が途中で切れたり、余計なスクロールが出たりします

---

## 起動前に初回だけやること（セットアップ）

1. このフォルダを任意の場所に展開します（例: デスクトップ）
2. `install.bat` をダブルクリックします
3. 「Setup completed」と出たら完了です
   - デスクトップに「SF6 Tracker Dashboard」ショートカットが作成されます

---

## ログインが必要なとき

1. デスクトップの「SF6 Tracker Dashboard」ショートカットをダブルクリックします
2. 左のサイドバーの「**初回セットアップ**」を開き、**プロフィールID**（10桁）を入力します
   - Buckler's Boot Camp で自分のプロフィールページを開いたときの、URL（`…/profile/〈10桁の数字〉`）の数字です
3. 「**自分の表示名**」にプロフィールに表示されている**プレイヤー名**を入力し、「**保存**」を押します
4. 「**データ更新**」ボタンを押す
5. ログインが必要な場合、ブラウザが開くので **Buckler（Capcomアカウント）にログイン**
6. アプリに「**ログイン完了**」ボタンが表示されるので押す

---

## 毎回の起動方法

1. デスクトップの「SF6 Tracker Dashboard」ショートカットをダブルクリックします
   - または `run_dashboard.bat` をダブルクリックしても起動できます
2. ウィンドウが開いてダッシュボードが表示されます
   - 起動時に最新バージョンを自動チェックし、更新があれば通知されます

---

## ショートカット／タスクバーへのピン留め

- `install.bat` を実行すると「SF6 Tracker Dashboard」ショートカットが自動作成されます
  - デスクトップと、インストール先フォルダ `%LOCALAPPDATA%\SF6Tracker\` の両方に作成されます
- **タスクバーに常駐させたい場合:**
  1. ショートカット（またはアプリ）から一度起動します
  2. タスクバーに出たアイコンを右クリック →「**タスクバーにピン留めする**」を選びます
- **ショートカットを消してしまった場合:**
  - `%LOCALAPPDATA%\SF6Tracker\` を開き、中の「SF6 Tracker Dashboard」ショートカットをデスクトップにコピー、またはそこから起動してピン留めし直してください
  - 見つからない場合は `install.bat` をもう一度実行すると再作成されます（アイコンやタスクバーのまとめ表示の設定込みで正しく復元されます）

## Steam から SF6 と一緒に起動する（任意）

1. エクスプローラーのアドレス欄に `%LOCALAPPDATA%\SF6Tracker` と入力して Enter を押します
2. 中の `launch_sf6_with_dashboard.vbs` を右クリック →「**パスのコピー**」を選びます（Windows 10 では Shift キーを押しながら右クリック）
3. Steam のライブラリで STREET FIGHTER 6 を右クリック →「**プロパティ**」を開きます
4. 「**一般**」の「**起動オプション**」に、次の形で入力します（〈コピーしたパス〉の所に貼り付けます）
   ```
   C:\Windows\System32\wscript.exe 〈コピーしたパス〉 %command%
   ```
   例:
   ```
   C:\Windows\System32\wscript.exe "C:\Users\（ユーザー名）\AppData\Local\SF6Tracker\launch_sf6_with_dashboard.vbs" %command%
   ```
5. 以後、Steam から SF6 を起動すると、ダッシュボードも一緒に立ち上がります
   - ダッシュボードがすでに開いているときは、ゲームだけが起動します

## データ更新方法

左のサイドバーの「**データ更新**」ボタンを押します。

> **こまめに更新してください**
>
> 公式サイトで見られる戦績は、各モードの直近100戦までです。それより前の試合は後から取得できません。
> また、バランス調整のアップデート（新キャラクター追加のときはほぼ毎回）が入ると、公式サイトの戦績が消えます。
> 100戦遊ぶ前と、大きなアップデートの前に更新しておくと、取りこぼしを防げます。

## 各ページの内容

| ページ | 内容 |
|---|---|
| ランクマッチ統計 | 自分のランクマッチの成績（レートの推移・セッションごとの成績など） |
| ランクメタ比較 | 自分のランクマッチの成績を、ほかのプレイヤーの傾向と比べる |
| メタ分析 | 世間の傾向（キャラの使用率・相性・ランクの人口分布など） |
| カスタム統計 | ランクマッチに限らず、あらゆるゲームモードの戦績の統計 |
| 試合ログ | これまで取得した、自分のすべての試合の記録 |
| プレイ傾向分析 | 試合中の行動（投げ・パリィなど）の傾向と、LEGEND プレイヤーとの比較 |
| 攻略メモ | コンボや考え方など、なんでもキャラや状況ごとにメモしておける |
| フレームデータ | 公式のフレームデータを、キャラ同士で比べたり条件で絞り込んだりできる |

## オーバーレイ（VS画面に戦績カードを出す）

対戦前の VS 画面で、そのキャラとの対戦での自分の戦績（勝率など）を、画面の上部中央にカードで表示します。

1. 左のサイドバーの「**オーバーレイ**」を開きます
2. 「**動作**」タブで「**オーバーレイを有効化**」をオンにし、「**使用モニター**」で SF6 を映しているモニターを選びます
3. 「**表示**」タブで、カードの大きさと表示する項目を選びます
4. 「**オーバーレイ設定を保存**」を押します

ダッシュボードの窓を閉じると、オーバーレイも止まります。

## データ保存場所

データは以下の場所に保存されます:

```
%LOCALAPPDATA%\SF6Tracker\
```

フォルダごとバックアップしておくと安全です。

## うまく動かないとき

- **A)** `install.bat` をもう一度実行する
- **B)** 〈起動前に初回だけやること〉をもう一度試す
- **C)** `run_dashboard_with_prompt.bat` で起動するとエラーログが確認できます

## アンインストール方法

1. アプリの窓を閉じます
2. Steam の起動オプションに設定している場合は、SF6 のプロパティを開いて起動オプションを空にします
   - **設定したままフォルダを削除すると、SF6 が起動できなくなります**
3. タスクバーにピン留めしている場合は、アイコンを右クリック →「**タスクバーからピン留めを外す**」を選びます
4. デスクトップに「SF6 Tracker Dashboard」ショートカットがあれば削除します
5. エクスプローラーのアドレス欄に `%LOCALAPPDATA%` と入力して Enter を押し、開いた場所にある「**SF6Tracker**」フォルダを削除します
   - **戦績データもこのフォルダに入っています。** 残したい場合は、削除する前にフォルダごと別の場所へコピーしておいてください
6. 最初に展開したフォルダ（「SF6Tracker_移行完了.txt」が入っているもの）が残っていれば、それも削除して構いません

**必要に応じて:**

- データ取得用のブラウザ（Firefox）は `%LOCALAPPDATA%\ms-playwright` に入っています。ほかに使っているアプリがなければ、このフォルダも削除できます
- Python は Windows の「設定」→「アプリ」から削除できます（ほかで使っていない場合のみ）
